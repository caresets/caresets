{% comment %} Content Security Policy. Every script, style, font and image the site needs is served from this origin, so 'self' is the whole allowlist: nothing third-party can execute, and no request leaks a visitor's IP to another host. script-src has NO 'unsafe-inline': every executable script is a file under assets/js/, so injected inline script will not run. That is the directive that actually mitigates XSS, as against merely blocking foreign origins. Page values reach those files through {% comment %} NOT deferred: pages load their own scripts in the body without defer, and a deferred script runs after the document is parsed - so those would run first and find window.SITE_CONFIG undefined. This reads the JSON block immediately above it, so running synchronously is safe. {% endcomment %} {% comment %} Export libraries, each loaded only if its format is switched on in _config.yml. jszip is for Excel and pdfmake for PDF; between them they are ~2.25 MB of third-party parsing code, so they are off by default. {% endcomment %} {%- if site.exports.excel -%} {%- endif -%} {%- if site.exports.pdf -%} {%- endif -%} {%- if site.exports.csv or site.exports.excel or site.exports.pdf -%} {%- endif -%} {%- if site.exports.print -%} {%- endif -%} {% include nav_filter.html %} {% include toc_filter.html %}
