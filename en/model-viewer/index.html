Element Structure

How to read this table

This is the structure as currently defined and published, with a few adaptations for readability.

Tree
The first row is the model itself. Rows indented below another row are the parts of that group; the triangle folds a group away or opens it. Expand All / Collapse All act on every group.
Element
The name of the data element. Hover it to read the full definition; the Description column shows the short text.
Card.
Cardinality, min..max: how many times the element may occur. 0..1 optional, 1..1 required, 0..* any number, 1..* at least one.
Type
The data type. BackboneElement is a group with its own rows below it; Reference(X) points to another model.
Glossary
The agreed glossary term the element is mapped to, when one exists; it links to the glossary.
Binding
For coded elements: the strength (required, extensible, preferred, example) and the ValueSet the codes come from, linked to its page in the FHIR release the model is expressed for.
